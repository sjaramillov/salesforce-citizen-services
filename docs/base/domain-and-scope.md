# Base recuperada: servicio ciudadano

El trabajo de origen separó una experiencia asistida de un sistema de registro. La persona quiere conocer estado, documento faltante, fecha y siguiente paso. Las excepciones requieren un funcionario y contexto suficiente para continuar la atención.

Se conserva ese dominio y el diseño existente del portal. Los ejemplos son ficticios y sus fechas son datos de escenario, no plazos vigentes ni instrucciones a ciudadanos reales. La referencia enmascarada y el número de caso sirven para demostrar la interacción; no autentican a nadie.

La base original contempla consulta y orientación. Las señales de escalamiento son mensajes o campos de contrato; no prueban transferencia a una cola humana. Las solicitudes nuevas y su revisión forman parte de la propuesta adicional del piloto.

Fuentes: `docs/demo-scope.md`, `docs/project-context.md`, componente `cscBenefitPortal` del proyecto `citizen-services-baseline`. La documentación distingue la demostración local de la integración objetivo.
